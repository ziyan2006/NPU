# 13 · 残差输出目标短程训练对照

日期：2026-10-01。本轮在电脑上训练候选，不改变 NPU RTL、模型图或当前板端权重；未写 SD 卡。

结论：修复跨库同曲隔离后，三组各 200 步训练及 143 段评估完成。**residual 是唯一通过初步浮点门的组别，但主要收益是少误删器乐，不是明显更强的消人声。** 它在 MUSDB 伴奏上只勉强越过改善阈值，人声残留诊断在多个域反而增加。保留研究候选，暂不升级部署；下一步优先做低频保护/频带布局的受控对照，而不是直接加大模型。

## 实验设计

起点为 `student_bott2_mir1k_candidate.pt`，SHA-256 `cb16d333c372d9558ef563b9b4baa9b9f7f46f0ec72d5b71f9e26557a1abfb55`。三个实验均保留 824,900 参数、128 legacy_log bands、两个瓶颈残差块、四个输出通道及 LF250 保护。

| 组别 | 训练目标 | 本次比较的问题 |
| --- | --- | --- |
| control | 原有独立人声/伴奏掩码，加权 band log-L1 | 新数据与继续训练本身有什么效果 |
| complement | 人声掩码 + `1-m_v` 的伴奏训练项 | 训练目标对齐实际残差输出是否有效 |
| residual | complement + 可微 iSTFT 后的波形误差 | 增加实际播放器重建误差是否有效 |

所有组同一初始权重、seed `20261001`、同一批次随机序列、同样 **200 步**，学习率峰值 `5e-6`、20 步 warm-up、余弦下降；不用运行时间决定步数。FP32 训练，TF32 关闭。

每个网络输入 96 帧历史 + 256 帧训练区域。band 损失排除历史预热；波形损失额外排除 STFT 两端边界。波形项为：

```text
mean_batch( mean((pred_vocal-reference_vocal)^2) / (mean(mixture^2)+1e-6) )
```

伴奏由 `mixture-pred_vocal` 得到，其尺度相关误差与人声误差相同，因此不重复计费。波形项权重为 1；总 band 损失为真值 0.6、教师锚点 0.4。低频保护使前 44 个 mask 通道在波形项中没有梯度，这是当前播放规则的真实限制，不是可通过此损失自动消除的低频人声。

每个真值批次包含 MUSDB×2、MIR×2、OnAir×1、器乐×1，另取 4 个教师频带片段。波形端变换人声音量 `-12/-6/0/+6 dB`、共同增益及声道交换，重新生成频谱与标签，不做幅度域近似 remix。

MUSDB 文件先检查 5 个 44.1-kHz 双声道音频流。用解码后的 drums+bass+other 求伴奏，加解码 vocals 构造精确相加的混音，**不把独立 AAC 编码的 mixture 流当作严格的 stem 和**。干净重跑在现有 94 首 train 中排除两首同曲，只解码剩余 92 首。训练阶段仅读取最终 test 的文件名进行隔离检查，不解码 test 音频；最终 test 音频在训练结束后才用于评价。这一 AAC 差异也见 [MUSDB 官方说明](https://sigsep.github.io/datasets/musdb.html#musdb18-compressed-stems)。

### 首次实验的隔离纠正

首次实验 `results/residual_finetune_20261001/` 虽然保持 MUSDB 原始 train/test 边界，却只按各数据集的原始 ID 检查重叠，遗漏了以下跨库同曲：

| Cambridge 专项片段 | MUSDB train 文件 | 首次实验中的用途 |
| --- | --- | --- |
| `Skelpolu_HumanMistakes` | `Skelpolu - Human Mistakes.stem.mp4` | 内部验证池 |
| `Triviul_Angelsaint` | `Triviul - Angelsaint.stem.mp4` | 训练池 |

因此首次实验中的 Cambridge 结果**不能称为独立留出**，首次三组门槛结论不作为模型升级依据。原文件保留作审计，不覆盖；本报告最终结论以 `results/residual_finetune_clean_20261001/` 的重新训练为准。没有沿用首次实验的微调权重，仍从冻结基线重新开始，组别、步数、损失权重和门槛都不变。

修复后先对曲名做 NFKC/casefold、去标点及扩展名的跨库规范化，再从训练与内部验证池中共同排除所有最终留出，并检查教师缓存。评估器也对所有数据域的训练/验证 ID 反向检查；单测涵盖同曲空格/下划线/`.stem.mp4` 别名。这是保守的标题/作者匹配，不是完整音频指纹或歌手隔离保证。

最终评估集已在首次实验看过，本次不是首次揭盲；重跑仅修复数据隔离，未根据首次测试成绩改变损失权重、训练步数或门槛。因此只作为本轮固定方案的烟雾测试，不视为全新盲测或多次模型搜索后的最终验收。

内部选 checkpoint 使用 9 个固定短窗：MUSDB/MIR/器乐各 3 个，域等权平均重建误差。验证 ID 从历史 train 池中划出，**不能保证初始权重从未见过它们**；19/9/3 是划出的 ID 数，不等于所有这些 ID 都参与了本轮短窗选模型。它只是微调选择尺，不是最终质量成绩。

本地旧教师缓存只有 6 首，不是旧报告的 245 首完整训练池。这是短程方向验证，不能声称已经完成充分蒸馏、长训练或商用模型升级。数据仍按随包教育/研究授权管理，不上传音频或候选权重。

### 最终评估口径

最终统一比较冻结基线及三组内部选出的 best，共 143 段：MIR 53、OnAir 6、mshoxx 31、MUSDB 原始 test 50、Cambridge 2、Demons 教师参考 1，对应 78 个歌曲 ID。片段在每个歌曲 ID 内先取平均，再对歌曲等权汇总；与报告 12 的片段等权均值不同，不能直接跨表相减。

每个最长 30 秒的评估片段内连续 FP32 上下文、LF250、TF32 关闭；不是每 16 帧重置，但片段之间不传状态。SI-SDR 沿用立体声展平、非去均值口径；尺度相关误差 SNR 另外检查响度与重建误差。人声评分排除人声 RMS≤`1e-5` 或人声/混音低于 -30 dB 的片段。两源联合拟合的人声残留系数仅是诊断，不是听感评分：更高的 SI-SDR 不必然等于更强的消声。

SI-SDR 的 dB 变化表示估计与参考分轨的接近程度，**不等于人声音量被压低了同样的 dB**。尤其伴奏平均分变高时，要同时看人声残留，避免用“少处理、更保真”冒充“消声更强”。

OnAir 使用对齐后的原始人声轨，伴奏参考是混音减该人声轨，母带差异可能影响成绩。Demons 使用此前固定的教师输出，**不是真分轨**，只用于防退化，不能作为人声真值改善证据。两个 Cambridge 是原始分轨合成的未母带混音。MUSDB 只使用约 7 秒官方样本，不能与完整 MUSDB18/BSSEval 论文成绩比较。本次离线 STFT 也不是逐样本板端前端仿真。

## 预先固定的浮点 smoke 门

候选先按内部验证选 best，再统一评价最终留出；不根据测试成绩重新选训练步数。

- MIR/MUSDB/OnAir 的歌曲等权人声及伴奏 SI-SDR 平均变化均不能小于 -0.15 dB。
- 纯器乐尺度相关伴奏误差 SNR 平均变化不能小于 -0.25 dB。
- 两个 Cambridge 片段及 Demons 教师参考反例，人声/伴奏不能退化超过 0.25 dB。
- 至少一个真实人声域的歌曲等权伴奏 SI-SDR 平均改善达到 +0.15 dB。

这些阈值只是预先声明的短程筛选规则，不是统计置信度或量产标准。即使通过，还要完成新权重的量化标定、完整整数链路回归、有状态任务及实板音质验收。

可评分的人声/伴奏若产生缺失或非有限指标，判失败，不通过过滤缺失分数来提高平均值；无真实人声的器乐不评分人声 SI-SDR。

## 结果

### 训练与模型一致性

干净重跑总用时 1,277.86 秒（约 21.3 分钟，含训练输入准备与内部验证）。三组都由内部验证选择第 200 步；未用最终留出挑 checkpoint。

| 组别 | 内部重建误差，初始 0.127097 | best 步数 | 初步浮点门 |
| --- | ---: | ---: | --- |
| control | 0.122713 | 200 | 不通过：DNB 伴奏退化超过 0.25 dB |
| complement | 0.122835 | 200 | 不通过：DNB 伴奏退化超过 0.25 dB |
| residual | 0.123101 | 200 | 通过，但不等于部署验收 |

三组 state-dict 的键和形状均与冻结基线相同，824,900 参数全部有限；没有增加卷积 MAC 或算子。验证了训练入口哈希、三个 best 的哈希、92 个 MUSDB 训练来源文件、17 个教师缓存以及三个数据清单。冻结 checkpoint 的 SHA-256 未改变。图不变不代表新定点尺度、整数精度和实板听感已经通过。

### 三组关键对照

下表均为相对于冻结基线的**歌曲等权配对平均变化**，单位 dB；正值表示该指标改善，不等于人声音量降低。

| 组别 | MUSDB 人声 SI-SDR | MUSDB 伴奏 SI-SDR | 电子器乐伴奏误差 SNR | DNB 伴奏 SI-SDR |
| --- | ---: | ---: | ---: | ---: |
| control | +0.522 | +0.226 | +0.995 | -0.510 |
| complement | +0.451 | +0.181 | +1.672 | -0.272 |
| residual | +0.392 | +0.151 | +2.111 | -0.161 |

普通继续训练组在 MUSDB 平均分上最好，却伤了 DNB 反例；残差波形组更保守、器乐误删更少，并非所有指标都最好。residual 的 MUSDB 伴奏变化实际为 **+0.151407 dB**，对 +0.15 dB 门槛仅多约 **0.0014 dB**；单 seed、小数据、没有置信区间，不能称为稳健升级。

| --- | ---: | ---: | ---: | ---: |
| MIR，20 首/53 段 | +0.033 | +0.038 | -0.017 | 14/20 |

电子器乐改善同时体现在尺度相关误差上，不只是 SI-SDR 的响度不敏感性造成。但 MIR/OnAir 几乎持平，其尺度相关误差还略退化；两个 Cambridge 合并的均值也会掩盖 DNB 退化，所以保留逐曲检查。

### 人声削弱仍未解决

| 人声残留联合拟合系数（越接近 0 通常表示越少残留，仅诊断） | 冻结基线 | residual |
| --- | ---: | ---: |
| MIR 歌曲均值 | 0.519 | 0.537 |
| OnAir | 0.510 | 0.536 |
| MUSDB 歌曲均值 | 0.499 | 0.524 |
| DNB：Human Mistakes | 0.745 | 0.733 |
| Electronica：Angelsaint | 0.340 | 0.367 |

多个域的残留系数增加，说明这轮不能宣称“消声更强”。DNB 的 residual 人声 SI-SDR 仍为 **-8.938 dB**（基线 -8.895），伴奏为 **12.489 dB**（基线 12.650）；还没有解决弱人声识别。Angelsaint 伴奏从 5.400 到 5.601 dB，但残留系数反而增大。两源拟合也受分轨相关性影响，不能把系数直接当作主观消声百分比。

### 决策与后续

1. 保留 residual 作为“少误删”的研究候选；control/complement 不作为升级候选，冻结部署权重继续保留。
2. 本轮固定 LF250，前 44 个输出频带在波形项中没有产品梯度。下一步先固定权重比较 LF250/LF120，逐域同时报告人声残留、器乐误删及 DNB，不只看伴奏均分；这属于后续诊断，不能把反复看过的集合重新宣称全新盲测。
3. 再做独立的 128-band `mel_unique` 训练对照：重新生成输入/教师标签，保持同等训练预算和同样卷积图，不给旧权重直接换矩阵。它针对 49 个空输入列和低频重建，不增加频带数。
4. 只有明确改善人声与伴奏取舍的候选才进入量化与任务编译：训练域标定、候选/尺度哈希绑定、完整 INT8/INT12 整数回归、跨块状态回归。板子回来后再验收听感与实时性。

这轮可以说明残差波形损失有小规模方向价值，但不能说明“无需新数据、无需布局优化，继续训练就会明显消人声”。没有更换镜像，也没有新实板结果。
