# 12 · 模型离线误差拆分与优化路线

日期：2026-10-01。板子暂不在手，本轮仅分析、离线评估和补充诊断脚本，**没有训练、替换权重或写 SD 卡**。

## 结论先说

目前应优先让模型“更准确地认出电子音乐中的人声，同时少误删乐器”，而不是直接增大参数量。

这次重跑了 90 段既有留出音频，并新增两个已下载电子音乐多轨片段的真值诊断。主要发现：

1. **低频保护确实留下了不少人声，但直接取消又会伤伴奏。** 这是训练需要解决的取舍，不能只靠加大消声力度。
2. **电子音乐人声识别仍有明显短板。** DNB 真分轨片段上，当前模型处理后的伴奏指标甚至不如不处理；调整低频保护并没有解决它。
3. **频带布局存在结构性浪费。** 128 个输入频带有 49 个空列；相同频带数量的 `mel_unique` 参考掩码重建更好，但旧训练探针没有把这种潜力稳定兑现。
4. **训练目标与播放器输出不完全一致。** 两个独立预测分支不一定互补，实际播放器只使用人声分支，伴奏由原音减人声得到。
5. **本轮输入 INT12 量化影响较小。** 后续仍应评估完整定点链路，但它不是这批样本上最优先的优化方向。

此前发现的“每 16 帧清空上下文”是另一个独立问题。已有状态保存实现和离线验证，但尚未完成新镜像的实板音质验收；本报告使用连续上下文，避免把这个实现问题混进模型质量判断。

## 1. 当前实际模型，不沿用立项估算

- 板端冻结 checkpoint：`models/student_bott2_mir1k_candidate.pt`。
- SHA-256：`cb16d333c372d9558ef563b9b4baa9b9f7f46f0ec72d5b71f9e26557a1abfb55`。
- 824,900 参数，两个瓶颈残差块，128 频带，线性幅度输入；无深度可分离/膨胀时间卷积块。
- INT8 权重、INT12 激活、INT32 累加；实数掩码，不预测复数相位。
- 每 16 帧 123,338,752 MAC，约 **1.328 GMAC/音频秒**。
- 当前实际 checkpoint 步数 **2855**，不是元数据中的计划上限 200000；本次微调用时约 5 分钟，继承此前已训练权重，不是从零训练 5 分钟。
- 微调训练采样：577 个教师片段重复两次，加 239 个 MIR-1K 真值片段；真值约占采样条目的 **17.2%**。重复不代表新增歌曲。

MIR 微调的教师验证 loss 从 0.94308 到 0.95584，最佳记录在第 1 步；但真实分轨指标改善。这说明当前教师验证 loss 不足以决定产品模型是否更好，**不能直接据此判断训练失败，也不能据此继续无限训练**。

## 2. 本轮评估范围与口径

| 数据 | 留出歌曲 ID | 片段 | 用途与局限 |
| --- | ---: | ---: | --- |
| MIR-1K | 20 | 53 | 分声道人声/伴奏真值；卡拉 OK，不能替代 EDM 泛化评估 |
| OnAir | 1 | 6 | 对齐后的原始人声轨；伴奏参考为混音减人声，母带处理差异仍可能影响指标 |

模型全程连续 FP32 推理，CUDA TF32 关闭，STFT 1024/256，沿用既有真值评估的 reflect 边界。它不是板端逐样本仿真，也不是扬声器录音。

表中 SI-SDR 为既有脚本的立体声展平、非去均值口径，越大越好；汇总是片段等权平均，**53 段不是 53 首独立歌曲**。MIR 按文件名歌曲 ID 隔离，不声称跨歌手或跨所有同曲翻唱隔离。没有用本次留出数据更新权重。

### 2.1 固定低频保护的取舍

下表是当前模型不同低频保护设置的**伴奏 SI-SDR**，模型权重不变：

| 保护设置 | MIR-1K | OnAir | 纯电子器乐 mshoxx |
| --- | ---: | ---: | ---: |
| 250 Hz，现状 | 1.681 | 3.824 | 23.750 |
| 120 Hz | 3.653 | 4.911 | 22.562 |
| 不保护 | 3.729 | 4.805 | 20.711 |

MIR 人声 SI-SDR 同时由约 -0.18 提升到 3.87 / 4.03；但纯器乐更容易被误删。其尺度相关伴奏误差 SNR 从 23.45 降到 21.85 / 18.82 dB，也支持“不是只改变响度”的判断。

这些样本人声 STFT 能量在 250 Hz 以下的片段平均占比：MIR **30.9%**，OnAir **27.7%**。这是这批音频的统计，不是所有歌声的固定比例，也不等于必须删除的全部能量。

结论：**120 Hz 可作为下一轮对照组，不能直接宣布替换 250 Hz。** 更好的目标是学会区分低频人声与贝斯，而不是始终保留或始终压低该频段。

### 2.2 新电子人声片段揭示了什么

| 伴奏 SI-SDR | Skelpolu · Human Mistakes | Triviul · Angelsaint |
| --- | ---: | ---: |
| 完全不处理 | 13.158 | 1.344 |
| 初始 K3S 基线，LF250 | 11.297 | 4.788 |
| 当前模型，LF250 | 12.650 | 5.400 |
| 当前模型，不保护低频 | 12.614 | 4.741 |
| 用真值构造 legacy_log 参考掩码，LF250 | 16.131 | 8.381 |
| 用真值构造 mel_unique 参考掩码，LF250 | 17.198 | 11.625 |

DNB 片段中人声较弱，单看伴奏指标容易被“不处理也很高分”误导。当前人声 SI-SDR 为 **-8.90 dB**；同样 legacy_log/LF250 处理的已知真值参考掩码为 **+0.69 dB**。这提示识别人声本身仍有较大误差，不是只差一个音量系数。

Cambridge 分轨按共同 sample zero 求和，短轨尾部补零，V 与 A 使用同一增益使混音峰值为 0.95。Skelpolu 评估 23.314 秒；Triviul 使用第一段 30 秒，保留短轨结束后的器乐尾部，未沿用旧下载报告的共同最短时长。两首只能作专项反例，不能估计整个电子音乐市场的成功率。

### 2.3 频带布局：值得改，但不能只换矩阵

FFT 间隔约 43.07 Hz，而 legacy_log 的部分低频三角窗比一个 FFT 间隔还窄，因此 **49/128 列没有输入，约 38.3%**；空列分散在 band 0..64，并非连续的前 49 列。被 LF250 保护的前 44 列中有 38 列为空。

用已知人声谱构造参考掩码、不做低频保护时，伴奏 SI-SDR：

| 参考掩码布局 | MIR-1K | OnAir |
| --- | ---: | ---: |
| legacy_log，128 bands | 6.603 | 8.417 |
| mel_unique，128 bands | 11.463 | 11.072 |
| 保留全 513 bins | 11.514 | 11.117 |

这些参考掩码使用测试答案，**不是模型可直接达到的成绩，也不是经过约束优化求出的理论上限**。尤其两种 band 布局的分析平均与合成插值方式不同，不能把全部差值解释为“空列占比”。它们只能证明相同 128-band 预算下，重建方式还有改善空间。

旧 `opt_mel_full` 训练实验在 14 个有效教师留出片段上的配对伴奏中位变化仍为 **-0.33 dB**，不能只引用参考掩码的改善而忽略训练结果。应重新生成缓存并适配训练分布；直接给当前权重换矩阵会改变输入语义。

### 2.4 独立双分支与产品公式

训练输出 `m_v`、`m_a` 两个独立掩码；实际播放只使用 `mix - vocal_est`，即伴奏掩码近似 `1-m_v`。

本轮排除启动区和空列后，`|m_v+m_a-1|` 平均约 MIR 0.080、OnAir 0.069、mshoxx 0.030。说明训练出的两个分支不完全互补，但**这项统计本身不能证明换损失就一定改善听感**。

同样 LF250 下，直接伴奏分支在 MIR/OnAir 伴奏指标约 1.75/3.85 dB，当前残差方式为 1.68/3.82，差距很小；在纯器乐上前者约 27.47、后者 23.75。没有一个分支在所有数据上都最好，不能直接更换播放器输出公式。

应优先实验：训练时令伴奏项使用 `1-m_v`，并通过实际合成矩阵及可微 iSTFT 评价 `mix-vocal`。旧 complement 探针仅带来约 +0.03 dB 的教师伴奏配对中位改善，需与真值训练结合，不能把它包装成已验证的大升级。

删除两个人声以外的输出通道只能少约 66 个参数；当前 O8 padding 还可能保留相同计算开销。**这不是主要的瘦身机会。**

### 2.5 量化优化应排在后面，但不能跳过

仅把模型输入量化到当前 INT12 步长 0.070468979，其余保持 FP32：

- MIR/OnAir 伴奏汇总指标变化不到约 0.01 dB。
- mshoxx 伴奏 SI-SDR 平均约下降 0.20 dB。
- 输入量化导致的非空列输出掩码 MAE 平均约 MIR 0.0087、OnAir 0.0085、mshoxx 0.0157。

这是**输入量化单项实验**，不包含 INT8 权重、内部激活、累加/重定标及 tanh LUT，不代表完整 NPU 没有精度损失。

旧量化报告的 `deploy12=25.62 dB` 是“与浮点输出的一致性”，不是“分离 SI-SDR 下降 25.62 dB”，也不能直接推断不可闻。建议后续按层定位完整整数误差，再做符合现有 INT8/INT12、RNE、残差重定标规则的 QAT；不要直接把训练端换成普通 INT8 模板。

## 3. 优化顺序与 NPU 影响

| 优先级 | 离线实验 | 要解决的问题 | 对当前 NPU 的影响 |
| --- | --- | --- | --- |
| P0 | 保持连续/有状态上下文作为所有模型比较的基线 | 避免每块重启造成周期掩码变化 | 已有实现，仍待实板音质验收 |
| P1 | 真值多域采样 + 残差输出一致的训练损失 | EDM 人声漏检、乐器误删、双分支目标不一致 | 保持图结构则主要更新权重、尺度、task payload |
| P1 | LF250/LF120/低频条件抑制对照 | 低频人声与贝斯的取舍 | 固定截止改动在 PS；条件方案需先评估，再设计部署 |
| P2 | 128-band mel_unique 与原布局严格 A/B | 空输入频带、粗糙重建 | MAC 数可保持；需重训并更新 PS 常量、缓存和绑定检查 |
| P2 | 当前整数链路误差定位 + QAT | 量化抖动与失真 | 正确保持算术规格时无需增加算子 |
| P3 | 低分辨率瓶颈加容量，或按 8 通道粒度重分配解码器容量 | 识别容量仍不足 | 需扩展当前固定导出器并重新编译、测周期 |

`mel_unique` 虽不必增加 NPU 卷积 MAC，但当前 `98_generate_stem_constants.py` 明确绑定 legacy_log；不能只换 checkpoint。深度可分离/膨胀时间块也不属于现有可直接部署范围：导出器拒绝 temporal blocks，卷积控制器要求 groups=1、dilation=1。

### 7020 是否允许更大模型

**有一定空间，但不宜按旧报告的 22 GMAC/s 估算继续放大。** 当前硬件是 64 MAC lanes、100 MHz，理想上限 6.4 GMAC/s；板上日志的 NPU 平均约 33.732 ms，对当前图的有效吞吐约 3.66 GMAC/s。

用户已有日志：整块平均约 59.1 ms，最坏约 61.3 ms；音频块预算 92.88 ms。以其他时间不变、NPU 时间线性增加的简化推算，翻倍 NPU 耗时会让整块接近 **92.8 ms**，几乎没有安全余量。这不是新模型实测，也没有计入新状态复制/cache 开销，所以不能保证两倍模型实时。

容量增加先放在瓶颈，不盲目拓宽高分辨率解码器：当前 dec2 占约 38.3% MAC，三个解码层合计约 73.6%；每新增一个相同的瓶颈 3×3 残差块，约 +147,584 参数、+4.72 M MAC/块，即当前总 MAC 的约 3.8%。参数增长和运行成本不是同一回事，仍需重新跑编译/周期门。

## 4. 下一轮建议的最小实验矩阵

先不改变通道数、频带数和 NPU 指令，分开比较，避免多个改动一起上而无法定位收益：

1. **基线冻结**：当前权重 + 连续上下文；保留 LF250，固定同一组真实分轨、DJ 留出和 DNB 反例。
2. **训练目标实验**：相同图、相同采样、相同步数，比较旧独立双分支损失与残差一致损失；补充实际重建误差，不只优化 band-domain log-L1。
3. **数据实验**：单独改变教师/真值/纯器乐采样比例，按数据域报告。真值 remix 在波形端做，不在压缩幅度域近似相加。两个 Cambridge 片段暂作专项验证，不同时拿来训练再宣称留出提升。
4. **低频实验**：每个候选同时测 250/120 Hz，报告人声残留、伴奏失真、纯器乐误删。确认双目标改善后再考虑学习型条件保护。
5. **再做布局与 QAT**：布局另建缓存、明确 checkpoint 元数据；QAT 通过完整整数解释器回归。都通过才生成新部署候选，不覆盖现有可回滚权重。

选择标准建议采用“多人声域改善 + 无人声不明显退化 + 关键反例不能大幅变差”的组合，而不是从单个平均分选择模型。小数据集给不出可靠的成功百分比，不能承诺人声彻底消失。

训练数据应继续遵循本地包的授权限制；两份 Cambridge Readme 明确仅教育用途。本次仅本地研究评估，不上传音频、不发布新权重。
