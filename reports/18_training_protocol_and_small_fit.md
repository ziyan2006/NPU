# 训练流程重整与小样本学习验证

日期：2026-10-01。**数据锁定和学习机制验证完成；正式训练与新歌/实板验收尚未开始。**
没有替换板端权重、没有写 SD、没有提交或推送本轮改动。

## 结论先行

当前图与优化器可以学习固定训练音频；新产品重建路径目标在本轮小样本上优于同条件
旧目标。这足以进入数据补强和正式对照的准备，不足以认定音质升级、电子乐泛化
或容量已足够。旧目标也能明显拟合，不能把之前受阻单独归因于它“完全无法学习”。

本轮采用文献训练纪律：先锁数据和验收边界，先检查学习能力，再预声明正式预算、
验证与停止规则；不是再次任意改一个权重跑 200 步然后宣称收敛。
详细配方与来源见[训练流程 v1](../docs/model_training_protocol_20261001.md)，
可执行设置见[JSON 协议](../docs/model_training_protocol_v1.json)。

## 原判断的修订

报告 08 的“训练损失差不多，所以数据无关/瓶颈只在目标”超出了现有证据。
历史训练下降、验证上升仍需考虑过拟合和域差异。旧频带权重切换新布局的短程失败
不是从零训练的架构结论；参考掩码构造也不是带 LF250 产品的严格可达上界。
已在报告 08 首页增加解释边界，而没有改掉原始实验数字。

同时，现行模型确有较长教师训练历史：K3S 245 首训练歌、577 个教师片段，后续
bott2 和 MIR-1K 微调。6 首/17 个 anchor 是当前本地缓存子集，不是全部历史训练。
最近的 200 步实验只是方向探针；也不能说整个模型从来没有充分训练过。

## 固定 TRAIN 小拟合

两个 MUSDB TRAIN 曲目：`ANiMAL - Clinic A.stem`、`ANiMAL - Easy Tiger.stem`。
依预声明排序、中心裁剪及人声活动门选择，两者是同一艺人，不能算多艺人泛化。
每曲原始与人声 -12 dB 各一段，共 4 视图。没有开发/测试/教师 loss，也没有数据增强。

824,900 参数 bott2、128 legacy 带、线性前端、LF250 的前 44 带保护全部不变。
每段 57,088 样本，96 帧预热；有效计分约 0.714 秒。两组同冻结起点、同四段音频、
Adam 1e-4、10 步 warm-up、有效批 4/microbatch 1、裁剪梯度 3、**各 400 更新**。
50 步检查只记录，最终以预声明第 400 步验收，没有途中见到过门就改预算。

实验组移除频带比例目标，以实际 Gs、实掩码边界、LF250 和 iSTFT 后的复数频谱
L1+波形 L1 训练；对照沿用频带 complement+波形 MSE。这不是改 Wa 为相位敏感
目标再平均的近似方案，而是通过真实产品重建映射回传梯度。
保护输出没有重建梯度；9 个 Wa 空列但 Gs 有效的未保护输出带有直接监督。

| 第 400 步 TRAIN 指标 | 旧频带+波形 MSE | 新重建 L1 |
|---|---:|---:|
| 普通人声 error-SNR 相对冻结增益 | +3.127 dB | **+3.876 dB** |
| 人声 -12 dB error-SNR 相对冻结增益 | +2.551 dB | **+4.290 dB** |
| 任一固定片段的最小增益 | +0.773 dB | +2.706 dB |
| 各自目标损失下降 | 81.26% | 34.63% |
| 预声明 TRAIN 学习门 | PASS | PASS |

两个损失定义/单位不同，**不能比较 81% 与 35% 就说旧目标更好**。
新目标在同一波形标尺上比对照多 +0.749 dB 普通、+1.739 dB 弱人声增益。
联合投影的剩余人声绝对系数均值：普通冻结 0.759 → 旧 0.423 / 新 0.344；
弱人声冻结 0.953 → 旧 0.632 / 新 0.560。仅为这两个训练片段的诊断，不是听感认证。

新目标自身损失从 0.347686 到 0.227268；旧目标 2.040258 到 0.382417。
两条曲线仍在变化；本轮不声称到达最优点或严格收敛。
相对报告 16/17，裁剪、学习率、数据选择和预算都不同，不能把本轮与它们的差额
单独解释为某一个因素的因果作用。有效对照仅是**本轮两组内部**。
