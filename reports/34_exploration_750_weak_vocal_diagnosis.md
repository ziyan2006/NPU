## 4. 损失审计：首要假设是目标取舍，不是已经证实的根因

当前 script150 调用 script143 导入的 **script126.backward_batch**；
不是历史 script120/122 的目标。实际每槽损失为：

```text
wave = mean(abs(pred_vocal - target_vocal)) / (rms(mix) + 1e-3)
complex = mean(abs(real_error) + abs(imag_error)) /
          (mean(abs(real_mix) + abs(imag_mix)) + 1e-3)
loss = equal-slot mean(wave + complex)
```

它使用产品前端、LF44 和 warmup/边缘排除；没有单独的弱人声权重，
也没有直接优化“伴奏中投影残留人声减少”的项。
分母是混音尺度，不是目标人声尺度。因此弱人声的相对漏估未被专门放大，
同时纯器乐约占 1/6 且伪标签占 1/2，存在优先减少误删的取舍。

但 **L1 对预测的梯度不因为目标变小就必然同比缩小**；仅凭上述公式不能确认
弱人声梯度不足。尚未测逐域/活动强度的梯度贡献，也未独立证明伪标签比例过高。
下一轮应通过同输入、同初始化的单变量对照检验，不能直接改活任务。

另一限制是 128 个实数频带掩码、混音相位及 LF44：
旧报告30的单源诊断显示低频保护可能限制部分 MIR 人声，但全局解除会损害器乐。
本轮普通/弱视图使用相同频带与 LF 策略，说明 LF44 不能单独解释全部强弱差异。
当前 CPU 开发评分已使用连续参考路径；旧板端上下文重启诊断也不能直接解释本轮曲线。
没有新板端测试，不宣称扬声器卡顿已改善。

## 5. 下一步决策顺序（尚未启动或授权新实验）

1. 先完成已授权的 1000 步，两教师臂均保持不变。核对终态、真实退出码、
   相符退出回执及实际无 worker，再做 script150 verify 和 script152 独立复核。
2. 若 1000 步仍持续减少残留且伴奏受保护，可提出 **额外最多 1000 共同步、总计 2000**
   的有限延长，并继续每 250 步评估；目前不支持直接加到 10000。
   需要新授权与显式兼容的完整模型/Adam/RNG/游标迁移证据，不能改旧 1000 步硬限
   或把旧 checkpoint 冒充新协议下的原生恢复状态。
3. 若 1000 步弱人声仍未改善，优先建议 **500 步的配对单变量对照**：
   同一已选教师、同输入/图/起点/优化器日程，一组原损失，
   另一组仅把真值 -12 dB 槽位权重设为 2 倍，以固定的加权均值规则实现。
   教师选择与新预算须先确认；此设计未获 GPU 实验授权，也未创建训练入口。
   同时监测普通人声、弱人声、伴奏保留和纯器乐，不以训练 loss 排名音质。
4. 根据活动/梯度审计再分别测试弱人声采样比例或目标尺度归一化。
   不同时改损失、采样、LF、模型宽度和数据集。
   如监督调整仍失败，再设计频带/LF 或容量的独立结构对照。
